# Tandau — подбор event-подрядчиков с объяснениями

> Прототип для HackAlem AI, трек 06 «Креативные индустрии», кейс Firebird «Умный подбор подрядчиков».

Команда **apex** · [репозиторий платформы](https://github.com/BAITC-Hacks/hack-ce6ddbc4-apex).

## Что делает проект

Tandau (таңдау — «выбор») задуман как сервис, который по параметрам мероприятия предлагает до трёх подрядчиков и объясняет выбор фактами. Если подходящих профилей нет, сервис должен объяснить причину и предложить, что изменить.

**Реализована фаза 1** по [спецификации](docs/PHASE_1_FOUNDATION_AND_LANDING.md): основной лендинг, бриф из пяти условий, черновик в текущей вкладке и гостевой экран `/app` с проверенной сводкой. Подбор, регистрация и личный кабинет ещё не реализованы; `/app` честно показывает, что сейчас доступен только подготовленный пример.

## Что реализовано

- **Лендинг `/`** на RU/KK/EN в утверждённом стиле Tandau: шапка, первый экран с карточкой события, бриф, шаги подбора, подписанный пример, каталог по локациям, ограничения данных, семь вопросов, финальное действие и подвал. Все кнопки ведут к существующим разделам.
- **Карточка события** в первом экране повторяет пять условий формы: локацию, крупную дату, формат, категорию и бюджет. Считаются только валидные поля («Заполнено 3 из 5 условий»). Изменения объявляются одной сдержанной сводкой для экранных дикторов.
- **Бриф из пяти обязательных условий**: радио-плитки города и формата, нативная дата с окном 23.09–31.12.2026, категория из 17 значений каталога с покрытием по локации, бюджет на одного подрядчика как целое число тенге. Ничего не выбрано заранее; пример заполняется только по явному действию.
- **Проверка на сервере и в браузере** по одним правилам (`app/brief.py` и `app/static/js/brief.js`): пробелы трёх типов в сумме, ведущие нули, предел `9007199254740991`, точное совпадение «Ведущий»/«Ведущий церемонии», повтор параметра как ошибка поля, неизвестные параметры отбрасываются.
- **Черновик** `tandau.brief.v1` в `sessionStorage` и снимок условий в адресе (`history.replaceState`). Явные параметры URL важнее черновика и не смешиваются с ним. Смена языка сохраняет условия через безопасный параметр `next`. Действия «Заполнить примером» и «Очистить» спрашивают подтверждение, если заменяют введённые значения.
- **Гостевой экран `/app`** показывает пустое, неполное, невалидное и готовое состояние. У каждого условия есть ссылка «Изменить» в нужное поле с переносом всех пяти значений. Поиск не вызывается, результатов и счётчиков кандидатов нет.
- **Пример подбора** из трёх реальных записей CSV (`HK-42352`, `HK-35215`, `HK-77838`): цена «от», остаток до лимита примера, факты о дате, языках и часах, цитата из описания и раскрытие «На чём основан пример» с исходными полями. Пример подписан и не меняется от личной формы; отсутствующая запись не подменяется.
- **Без JavaScript** работают навигация, GET-форма, серверные ошибки, раскрытия и ссылки категорий. Кнопки, которым нужен JS, в этом режиме скрыты.
- Предметные 3D-изображения из пакета пользователя подключены как акценты секций после проверки (по одному на секцию, веб-копии JPEG, отложенная загрузка). Подробности в [реестре графики](docs/TANDAU_ASSET_INVENTORY.md).
- [Дизайнбук](http://127.0.0.1:8000/designbook) и [макет лендинга](http://127.0.0.1:8000/designbook/landing) остаются командными эталонами.
- Загрузка CSV (66 профилей, 17 категорий, 3 локации), API состояния и справочников, подписанные сессии, автоматические проверки.

## Как это работает

При запуске `matcher/data.py` читает CSV в UTF-8, разбирает списки через `|`, булевы значения `True`/`False`, цены и длительности. Пустой `max_hours` превращается в `None`, занятые даты — в неизменяемое множество. Категории сравниваются по целому элементу: «Ведущий» и «Ведущий церемонии» различаются.

Каталог строит индекс по ID и считает категории по городам. FastAPI передаёт эти данные в Jinja2-шаблоны и JSON API. Категории упорядочены по убыванию количества профилей, затем по названию. Сведения для демонстрационных карточек берутся из CSV, тексты объяснений заданы в словарях переводов.

## Технологии

Python 3.10+, FastAPI и Uvicorn; серверный HTML через Jinja2; обычные CSS и JavaScript. Для сессий используются Starlette SessionMiddleware и itsdangerous, для тестов — pytest и httpx. Node.js, сборка фронтенда и сервер базы данных не нужны.

Зависимости фиксируются диапазонами в `requirements.txt`:

```text
fastapi>=0.110,<1.0
uvicorn>=0.27,<1.0
jinja2>=3.1,<4.0
python-multipart>=0.0.9
itsdangerous>=2.1,<3.0
pytest>=8.0,<9.0
httpx>=0.27,<0.28
```

## Установка и запуск

Нужен Python 3.10 или новее. Локальная проверка выполнена на Python 3.12. Для первоначальной установки зависимостей нужен доступ к PyPI.

Если файлы проекта уже скачаны, откройте их папку и пропустите клонирование.

```sh
git clone https://github.com/BAITC-Hacks/hack-ce6ddbc4-apex.git tandau
cd tandau
```

macOS / Linux:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python run.py
```

Windows, PowerShell или cmd; активация окружения не требуется:

```powershell
py -3 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe run.py
```

Откройте [http://127.0.0.1:8000](http://127.0.0.1:8000). Остановить сервер можно сочетанием `Ctrl+C`. Настройка `.env`, регистрация, API-ключи и отдельная БД для запуска не нужны.

## Демо-доступ

Все реализованные страницы и API доступны без входа. Демо-аккаунт пока не создан: он запланирован вместе с авторизацией в фазе 3. Шапка не показывает вход и регистрацию; страницы `/login` и `/register` доступны по прямому адресу и сообщают о статусе разработки.

## Как проверить решение

1. Запустите приложение по инструкции выше и откройте главную страницу. Проверьте числа **66 профилей · 17 категорий · 3 локации** в первом экране и отметку о 13 синтетических профилях в блоке ограничений данных. Форма пуста, карточка события показывает «Заполнено 0 из 5 условий».
2. Переключите язык через «RU», «ҚАЗ», «EN», обновите страницу: выбор сохраняется. Прямые примеры: [казахский](http://127.0.0.1:8000/?lang=kk), [английский](http://127.0.0.1:8000/?lang=en).
3. Откройте [проверку состояния](http://127.0.0.1:8000/healthz): ответ `{"status":"ok","profiles":66}`.
4. Откройте [справочники каталога](http://127.0.0.1:8000/api/meta): 17 категорий с распределением по городам, 6 форматов, 3 языка и окно `2026-09-23`–`2026-12-31`. Для категории «Ведущий» указаны 10 профилей в Алматы и 5 в Астане.
5. Проверьте [Swagger UI](http://127.0.0.1:8000/docs) и [схему OpenAPI](http://127.0.0.1:8000/openapi.json). Доступные прикладные API этой фазы — `GET /healthz` и `GET /api/meta`.
6. Нажмите «Продолжить» с пустой формой: появится сводка ошибок со ссылками на поля. Заполните пять условий, карточка события в первом экране обновится.
7. Отправьте форму: [/app](http://127.0.0.1:8000/app?city=%D0%90%D0%BB%D0%BC%D0%B0%D1%82%D1%8B&date=2026-10-17&event_type=%D1%81%D0%B2%D0%B0%D0%B4%D1%8C%D0%B1%D0%B0&category=%D0%92%D0%B5%D0%B4%D1%83%D1%89%D0%B8%D0%B9&budget=1000000) покажет «Условия готовы» и переход к примеру. «Изменить» у любого условия возвращает в его поле, остальные значения сохраняются.
8. Смените язык и обновите страницу: условия остаются. «Очистить» удаляет их из формы, адреса и вкладки.
9. Проверьте ссылку с ошибкой, например [неизвестный город и бюджет 0](http://127.0.0.1:8000/app?city=Moscow&budget=0): сводка не станет успешной и укажет, что исправить.
10. `/login` и `/register` возвращают HTTP 200 и показывают, что вход появится позже.

## Данные и внешние сервисы

Файл `data/hackathon-dataset-anonymized.csv` — анонимизированный датасет организаторов кейса Firebird: 66 профилей, 13 колонок. [Исходный CSV](https://drive.google.com/file/d/1uUCu-szctwaTaV0-Yfg3FKHY8M3lQ3vw/view). Правила и проверенные примеры собраны в `docs/01_REFERENCE.md`.

В каталоге 13 синтетических профилей, у 18 цена проставлена при подготовке данных, у 8 таким же образом указан город. Эти флаги сохраняются в модели и помечаются на демонстрационных карточках при наличии. Категории могут пересекаться: одна площадка бывает одновременно банкетным залом, рестораном и отелем, поэтому сумма численностей категорий превышает число профилей.

Период календаря задан организаторами: **23 сентября — 31 декабря 2026 года, 100 дней включительно**. Его границы не выводятся из первой и последней занятой даты: свободные дни тоже входят в период.

Во время работы основной интерфейс и каталог не обращаются к внешним сервисам. После установки зависимостей они работают без сети. Стандартный Swagger UI FastAPI загружает свои JS/CSS с CDN и может требовать интернет; JSON API и `/openapi.json` доступны локально. LLM не используется, ключи внешних моделей не нужны.

## Переменные окружения

Все настройки необязательны. При необходимости скопируйте `.env.example` в `.env` в корне проекта. `app/config.py` читает этот файл; уже заданные переменные процесса имеют приоритет. `.env` и `var/` исключены из Git.

| Переменная | Значение по умолчанию | Использование |
| --- | --- | --- |
| `SECRET_KEY` | Генерируется автоматически | Подпись cookie сессии; сохраняется в `var/secret_key` для следующих запусков |
| `DATABASE_PATH` | `var/tandau.db` | Путь для будущих фаз; SQLite пока не создаётся |
| `LLM_MODE` | `off` | Резерв для будущего LLM-слоя; сейчас вызовов LLM нет при любом значении |
| `OPENAI_API_KEY`, `OPENAI_MODEL`, `OPENAI_BASE_URL` | Пусто | Резерв для будущего LLM-слоя; сейчас не используются |
| `HOST` | `127.0.0.1` | Адрес сервера; задаётся в `.env` или окружении процесса |
| `PORT` | `8000` | Порт сервера; задаётся в `.env` или окружении процесса |

При смене `SECRET_KEY` или удалении `var/secret_key` ранее выданные сессии становятся недействительными. `requirements-llm.txt` относится к будущей необязательной интеграции; для текущей версии его устанавливать не требуется.

## Тесты

Из корня проекта, с активированным виртуальным окружением:

```sh
python -m pytest -q
```

Windows без активации:

```powershell
.venv\Scripts\python.exe -m pytest -q
```

Проверки охватывают статистику и парсинг исходных данных, точное различение категорий, известные даты занятости, отклонение повреждённых записей, API, страницы, язык и настройки. Для фазы 1 добавлены `tests/test_brief.py` (бюджет, дата, справочники, повтор параметров, контракт запроса) и `tests/test_landing.py` (пустое состояние, предзаполнение, состояния `/app`, экранирование, безопасный `next`, факты примера, частично недоступный пример, совпадение ключей и параметров трёх словарей). Для проверки самого каталога: `python -m pytest tests/test_data.py -q`.

Каждую завершённую задачу с изменениями фиксируем коммитом и отправляем в `origin/main`. Перед push запускаем `python -m pytest -q` и проверяем `git status`: `.env`, `var/` и виртуальное окружение не должны попадать в коммит.

## Ограничения

- Реализованы фазы 0 и 1. Фильтры, ранжирование, персональные объяснения, авторизация, история и избранное будут добавляться в следующих фазах. Черновик хранится только в текущей вкладке браузера.
- Каталог анонимизирован, часть профилей синтетическая. Он служит демонстрационным набором и не подтверждает реальную доступность исполнителей.
- Цена означает «от» за мероприятие, а не согласованную смету. Проставленные при подготовке цена и город требуют проверки для реального заказа.
- Календарь покрывает только установленное окно 2026 года. Модель не подтверждает доступность за его пределами.
- Тексты демонстрационных карточек заданы заранее; это не результат API рекомендаций. Их исходные данные и сценарий указаны в справочнике.
- Приложение настроено для локального HTTP-запуска. Развёрнутой публичной версии в этой документации пока нет.

## Использованные компоненты и AI-инструменты

Приложение использует FastAPI/Starlette, Uvicorn, Jinja2, itsdangerous, python-multipart, pytest и httpx; версии ограничены в `requirements.txt`. Основные стили и JavaScript находятся в проекте, внешние шрифты и библиотеки интерфейса не требуются. Данные предоставлены организаторами кейса Firebird.

Дизайнбук использует локальный Geist из официального пакета `geist@1.7.2` (SIL Open Font License, текст в `app/static/fonts/Geist-OFL.txt`). Прежние десять PNG перенесены в `app/static/assets/tandau/archive/` и не отображаются. Происхождение и контрольные суммы сохранены в `app/static/assets/tandau/manifest.json`. В интерфейсе доступен набор функциональных SVG-иконок, включая шесть иконок форматов мероприятия. Из шестнадцати изображений по [брифам](docs/TANDAU_ASSET_BRIEFS.md) получено четырнадцать. Одиннадцать прошли проверку и сохранены веб-копиями в `app/static/assets/tandau/img/`, пять из них уже используются как акценты секций. Три отклонены из-за чужих логотипов или несоответствия сюжету. Новая серия состоит из оборудования для мероприятий и предметов для подбора. Макеты доступны по `/designbook` и `/designbook/landing`.

**Codex** и **Claude Code** использованы как AI-агенты для написания кода, переводов, тестов и документации. Сервис не вызывает AI-модели во время обработки HTTP-запросов этой версии.

## Языки интерфейса

Русский (`ru`, по умолчанию), казахский (`kk`) и английский (`en`). Плоские JSON-словари находятся в `app/i18n/`. Язык выбирается по `?lang=`, затем cookie `lang`, затем предпочтению пользователя, если оно появится в следующих фазах, и наконец `ru`. Переключатель сохраняет cookie на год.

Отсутствующий перевод берётся из русского словаря; если ключ отсутствует и там, показывается сам ключ. Значения каталога внутри модели и API остаются на русском, как в CSV; для интерфейса используются ключи `data.*`. Переводы основаны на глоссарии из `docs/01_REFERENCE.md`; участник 2 может дополнительно проверить казахскую редактуру.
