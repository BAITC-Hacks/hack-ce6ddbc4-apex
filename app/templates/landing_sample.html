Вопросы

Перед подбором.

Нужна ли регистрация?+

Гостевой подбор предусмотрен без регистрации. Аккаунт нужен для истории и избранного. На этом макете отметки сохраняются только до перезагрузки страницы.

Откуда берутся подрядчики?+

В демонстрации используется предоставленный каталог из {{ stats.profiles }} анонимизированных профилей. Среди них {{ stats.synthetic }} синтетических. Соответствующие пометки сохраняются на карточках.

Можно ли сразу забронировать?+

Нет. Tandau помогает сравнить профили. Бронирование и оплата не входят в этот прототип.

Почему цена указана «от»?+

Это стартовая цена из каталога. Итог зависит от состава услуги. Если значение проставлено при подготовке данных вместо отсутствующей цены, карточка показывает «Цена ориентировочная».

Какие даты доступны в каталоге?+

Период данных с 23 сентября по 31 декабря 2026 года включительно. Дата в образце формы ограничена этим периодом.
