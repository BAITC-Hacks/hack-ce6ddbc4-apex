Объяснение / образец

У каждого выбора
есть основание.

Город + категория: 10Далее: дата → формат → бюджет

В продукте каждый счётчик берётся из движка. Один подрядчик может нарушать несколько условий: сумму причин нельзя выдавать за число исключённых.

Сравнение: удерживаем все условия и меняем только дату. Ушедший из выдачи подрядчик получает конкретную причину «занят на вторую дату».

  • 320–1440 px без горизонтального скролла страницы.
