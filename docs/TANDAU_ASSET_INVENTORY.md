# Tandau — реестр изображений и шрифтов

**Версия 2.0 · 23 сентября 2026**

Этот реестр отделяет то, что уже получено и используется, от будущих изображений и локального архива. Он не заменяет дизайнбук: геометрия, компоненты и способы применения описаны в [`TANDAU_DESIGNBOOK.md`](TANDAU_DESIGNBOOK.md).

## 1. Статус пакета

| Группа | Количество | Статус | Использование |
| --- | --- | --- | --- |
| Выбранная синяя волна `fluid-card.png` | 1 файл | Получен, выбран пользователем | Hero, декоративные области auth и экранных образцов |
| Собственные новые изображения Tandau | 10 заданий | Pending — пользователь будет генерировать | Подключаются после получения, проверки и утверждения |
| Собственные функциональные SVG-иконки | 1 спрайт, 16 символов | Готов | Кнопки, поля, навигация, фильтры, статусы |
| Локальный variable font Geist | 1 WOFF2 + лицензия и provenance | Получен, подключён | Весь интерфейс и дизайнбук |
| Старые растровые PDF-фрагменты | 9 файлов | Архив, не production | Только локальная воспроизводимость; не отображать в продукте |

Текущий дизайн не зависит от того, когда будут готовы десять новых изображений. Полноценные текст, кнопки, формы, карточки, объяснения и пустые состояния работают без них. В продуктовых экранах не оставлять пустые ячейки, фиктивные финальные изображения или сломанные ссылки ради демонстрации будущего набора.

Будущие пути изображений определяются в [`TANDAU_ASSET_BRIEFS.md`](TANDAU_ASSET_BRIEFS.md). Их не нужно создавать как пустые файлы. Когда пользователь передаст изображения, принятые веб-копии попадут в активную папку с однозначными Tandau-именами; оригиналы сохраняются отдельно от оптимизированных копий. Manifest обновляется по факту, а не заранее выдаёт pending-файл за существующий.

**Правила применения:**

- Сохранять пропорции. Допускается обрезка контейнером через `object-fit: cover`; сам исходник не растягивать.
- Сохранять насыщенный синий цвет без фильтров, recolor, blend-mode или накладываемых градиентов, меняющих выбранную пользователем волну.
- Декоративный контейнер имеет radius 0. Скругление самого изображения не вводит новую геометрию.
- Обязательные поля, цены, объяснения и статусы располагаются на однотонной поверхности рядом.
- Изображение не означает, что интерфейс умеет бронировать, проверяет личность подрядчика или подтверждает доступность.
- В hero/auth файл декоративный: `alt=""`, явные `width` и `height`, без фокуса и без обработчика нажатия.
- Сохранять выбранную волну при добавлении новых изображений. Замена требует отдельного художественного решения, а не происходит автоматически после генерации нового файла.

## 4. Десять собственных ассетов: ожидаемый пакет

Точные сюжеты, ID, размеры, композиции, фон и готовые задания находятся в [`TANDAU_ASSET_BRIEFS.md`](TANDAU_ASSET_BRIEFS.md); машинный пакет — [`asset-briefs.json`](../app/static/assets/tandau/asset-briefs.json). **Все десять новых изображений пока pending.** Пользователь генерирует их самостоятельно. Бриф — описание ожидаемого результата, а не полученное изображение.

В реестре каждого файла после получения нужны:

| Поле | Требование |
| --- | --- |
| `id` | Совпадает с ID из брифа, не зависит от случайного имени загрузки |
| `status` | pending / received / inspected / approved / integrated / revision_requested |
| `original_file` | Реальное имя полученного оригинала; пусто до получения |
| `web_file` | Реальный путь принятой веб-копии; пусто до подготовки |
| `source` | «Предоставлено пользователем» и известные подробности; неизвестное не придумывать |
| `received_at` | Дата фактического получения |
| `width`, `height`, `format` | Измеряются по файлу |
| `alpha` | Фактический alpha-канал; картинка шахматной сетки не является прозрачностью |
| `sha256` | Контрольная сумма конкретной версии файла |
| `usage` | Разрешённые места применения, без подмены функциональных фактов |
| `crop` | Проверенная позиция кадра для desktop/mobile |
| `alt` | Пустой для декора или локализованное описание для смыслового изображения |
| `review_notes` | Недочёты, ограничения и решение по интеграции |

Не помещать новое изображение в карточку анонимизированного подрядчика как его портрет. Категорийная иллюстрация — иллюстрация услуги, а не фотография конкретного исполнителя или места. Знак «успех» не означает гарантию бронирования. Изображение календаря не заменяет календарные данные CSV.

## 5. Проверка поступивших изображений

1. **Соответствие брифу.** Проверить объект, композицию, направление света, перспективу, свободное поле и назначение. Проверка проводится на оригинале, а не только на уменьшенной миниатюре.
2. **Самостоятельная идентичность.** Нет посторонних логотипов, названий, водяных знаков, случайной типографики и декоративных UI-скриншотов.
3. **Материал и цвет.** Согласованные стекло/синий/холодные нейтральные материалы; никаких новых вторых фирменных акцентов.
4. **Фон.** Для отдельного объекта — требуемая брифом прозрачность. Для сцены/фона — цельная поверхность без видимых швов. Проверить края на белом и на Navy.
5. **Размер и резкость.** Исходник достаточен для целевого отображения; нет растяжения, заметных артефактов и обрезанных важных частей.
6. **Кропы.** Desktop и mobile проверены отдельно. Ключевой объект не исчезает при узком кадре.
7. **Веб-оптимизация.** Сохранить оригинал; подготовить подходящую локальную копию. Сжатие не разрушает стеклянные блики и границы. Явные размеры предотвращают сдвиг страницы.
8. **Смысл и доступность.** Интерфейс читается без изображения. Декор исключён из дерева доступности через пустой alt. Никаких доказательств, существующих только в картинке.
9. **Реестр.** Обновить статус и manifest только после успешной проверки. Записать точное место интеграции.

Если пункт не выполнен, записать конкретную правку и оставить `revision_requested`. Не отмечать ассет integrated только потому, что его файл можно открыть.

## 6. Готовый набор функциональных иконок

Файл [`tandau-icons.svg`](../app/static/assets/tandau/tandau-icons.svg) — собственный векторный спрайт Tandau. Он содержит **16 символов 24 × 24**, выполненных линией 1.5 с `currentColor`, `stroke-linecap="square"`, `stroke-linejoin="miter"`. Контрольная сумма текущего файла: `9e224e61d1f0554224ae627e94bf872318231990b2689c11fdc616359360e28a`.

| Symbol ID | Смысл в интерфейсе |
| --- | --- |

| `check` | Подтверждённое состояние |
| `close` | Закрыть или удалить условие |

| `compare` | Сравнение дат/вариантов |

Иконки готовы и не зависят от генерации десяти изображений. Отображать в 16, 20 или 24 px, сохранять согласованную толщину линий. Контейнер кнопки имеет radius 4, зона взаимодействия минимум 44 × 44. Иконка рядом с текстом декоративная; icon-only button получает доступное имя, например «Добавить Кики в избранное».

Собственный знак выбора из трёх полос выполнен кодом интерфейса и не является отдельным сгенерированным изображением. Он не увеличивает количество ожидаемых ассетов. Круглая форма внутри смыслового рисунка лупы/часов не меняет прямоугольную геометрию кнопок и панелей.

| Provenance | [`geist-provenance.json`](../app/static/fonts/geist-provenance.json) |
| Метод проверки | Unicode cmap соответствующего TTF из того же проверенного пакета; WOFF2 отдельно не декодировался |

Проверенные тестовые алфавиты: русский, английский и казахские буквы `ӘҒҚҢӨҰҮҺІәғқңөұүһі`. В соответствующей карте TTF 728 codepoints. Знак тенге `₸` отсутствует, поэтому стек CSS сохраняет системный fallback. Проверка наличия букв не подтверждает каждую пунктуационную форму или весь Unicode; в браузере остаётся обязательная строка проверки глифов.

Текущая шкала Tandau: Display **64 px desktop / 40 px mobile**, H1 44, H2 32, H3 22, Body **16 px Regular 400**, Label 14. Light 300 может использоваться для крупных чисел; длинные объяснения и обязательные подписи не набираются сверхтонким весом. Шрифт загружается локально; внешняя сеть для отображения не нужна.

## 9. Приёмка всего пакета

- [ ] Выбранная волна загружается из папки Tandau, сохраняет цвет и пропорции.
- [ ] Геометрия экрана соответствует токенам: поверхности 0, контролы 4, метки 2, overlays 8 px.

- [ ] Брифы и реальные имена файлов согласованы; битых ссылок нет.

- [ ] Информация о цене, происхождении и доступности остаётся настоящим текстом рядом с карточкой.
- [ ] README описывает фактически полученные и подключённые материалы, а не весь запланированный набор.
